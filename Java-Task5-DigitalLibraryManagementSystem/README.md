# Digital Library Management System

**Internship:** OASIS INFOBYTE  
**Track:** Java Development  
**Task:** Task 5

## Project Description

A web-based Digital Library Management System designed to manage books, users, book issuing, returns and reservations.

## Technologies Used

- Java
- Spring Boot
- MySQL / PostgreSQL
- HTML
- CSS
- JavaScript

## Main Features

- Admin and User roles
- User registration and login
- Book catalog management
- Book issuing and returning
- Due date and fine management
- Book reservation
